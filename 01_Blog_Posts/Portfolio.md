# 임민성

> [!abstract] 게임의 규칙을 구현하고, 문제를 기록하며 개선합니다.
> C++ 콘솔 게임 두 편을 제작하며 블록 탐색과 낙하 규칙, 터미널 렌더링, 맵 생성과 경로 탐색을 구현했습니다. 동작하는 결과와 설계·문제 해결 과정을 함께 정리합니다.

같은 색 블록을 하나의 그룹으로 처리하는 퍼즐 게임에서 시작해, 터미널 문자 셀로 공간을 표현하는 1인칭 좀비 탈출 게임으로 구현 범위를 넓혔습니다. 기능을 추가하는 과정에서 생긴 결합도와 출력 비용을 돌아보고, 다음 수정에서도 결과를 비교할 수 있도록 검사 구조를 마련했습니다.

Mr.Driller-C는 수업에서 구현한 콘솔 엔진을 바탕으로 만든 교육 프로젝트입니다. Console Zombie의 코드 구현과 자동 검사는 주로 AI 코딩 도구와 협업해 진행했고, 저는 요구사항과 구현 범위를 정하고 플레이·코드·검증 결과를 검토하며 수정 방향을 제시했습니다. 각 프로젝트에서 본인이 맡은 부분과 AI의 작업 범위를 함께 밝힙니다.

## 문제를 해결한 방식

**블록을 하나씩 처리할 때 생기는 오류를 그룹 단위 규칙으로 바꿨습니다.** Mr.Driller-C에서는 같은 색 블록의 연결 범위를 먼저 모으고, 그룹 바닥의 이동 가능 여부를 확인한 뒤 함께 이동시켰습니다. 깊이가 증가할 때 처리 대상이 쌓이는 문제는 카메라 기준으로 지나간 객체를 정리하는 방식으로 다뤘습니다.

**기능 확장 과정에서 출력 비용과 중복된 규칙을 정리했습니다.** Console Zombie에서는 터미널 출력 버퍼의 문자열 생성 방식과 여러 곳에 흩어진 게임 규칙을 돌아봤습니다. 자동 검사와 결과 다이제스트를 비교해 수정 전후 동작을 확인하는 구조를 마련했습니다. 세부 구현과 기존 검증 기록은 각 프로젝트의 상세 글에 정리했습니다.
